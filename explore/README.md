# explore/

Scripts usados para mapear ao vivo a interface dos sistemas Astor Tech e Nova Vida
(login, navegação, seletores, opções de dropdown) antes de implementar o código de
produção em `src/`. Mantidos como referência de como cada seletor/fluxo foi confirmado.

Saídas (`screenshots/`, `dumps/`) são git-ignoradas por poderem conter dados reais de
clientes capturados durante a exploração.
