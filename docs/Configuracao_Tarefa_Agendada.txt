  14:00

  16:00
  17:00

  Observacao: essa data e' apenas a referencia inicial de cada CalendarTrigger;
  como a repeticao e' semanal (WeeksInterval=1) e os dias uteis estao marcados,
  a tarefa continua disparando indefinidamente nesses horarios, nesses dias,
  independente da data atual.

6. PRE-REQUISITOS NA MAQUINA DE DESTINO (fora do Agendador)
==================================================================
Para a tarefa funcionar de forma identica em outra maquina, alem de recriar
o agendamento acima, e' necessario:

a) Copiar o projeto completo (pasta automacaoBaseClientes) para a nova maquina,
   incluindo o codigo em src/ e config/.

b) Criar o ambiente virtual Python no mesmo caminho relativo do projeto e
   instalar as dependencias:
     python -m venv .venv
     .venv\Scripts\pip install -r requirements.txt

c) Criar um arquivo ".env" na raiz do projeto (nao versionado, contem
   credenciais) com base no modelo ".env.example". Variaveis necessarias:
     ASTOR_URL, ASTOR_USER, ASTOR_PASS
     NOVAVIDA_USER, NOVAVIDA_PASS, NOVAVIDA_EMPRESA, NOVAVIDA_URL
     NOVAVIDA_CAMPANHA, NOVAVIDA_SUBCAMPANHA, NOVAVIDA_PROCESSO,
     NOVAVIDA_LAYOUT_ENTRADA, NOVAVIDA_LAYOUT_SAIDA
     VALOR_MIN, VALOR_MAX
     INTERVALO_HORAS (usado so no modo "loop continuo", nao no modo --once
     usado pela tarefa agendada)
     FILTRO_HORAS_CONSULTA
     EMAIL_SMTP_HOST, EMAIL_SMTP_PORT, EMAIL_REMETENTE, EMAIL_SENHA,
     EMAIL_DESTINATARIO
   IMPORTANTE: os valores reais (usuarios, senhas, senha de app do e-mail)
   NAO estao neste relatorio por seguranca. Devem ser copiados manualmente
   do arquivo .env original ou re-cadastrados.

d) Se o caminho do projeto na nova maquina for diferente de
   "C:\Users\cesar.barros\Desktop\automacaoBaseClientes", ajustar tanto o
   "Iniciar em" quanto o caminho do executavel na acao da tarefa (item 3).

7. COMO RECRIAR A TAREFA (RESUMO PRATICO)
==================================================================
Passos no Agendador de Tarefas do Windows (taskschd.msc) na maquina nova:

1. Criar Tarefa (nao "Tarefa Basica", para poder configurar os 10 gatilhos).
2. Aba Geral:
   - Nome: Automacao Astor Tech - Nova Vida
   - Descricao: (ver item 1 acima)
   - Executar apenas quando o usuario estiver conectado
   - NAO marcar "Executar com privilegios mais altos"
3. Aba Disparadores: criar 10 gatilhos "Semanalmente", repetir a cada 1
   semana, dias marcados = seg/ter/qua/qui/sex, um gatilho para cada horario:
   08:00, 09:00, 10:00, 11:00, 12:00, 13:00, 14:00, 15:00, 16:00, 17:00.
4. Aba Acoes: Nova acao "Iniciar um programa":
   - Programa/script: <caminho do projeto>\.venv\Scripts\python.exe
   - Adicionar argumentos: -m src.orchestrator --once --permitir-consulta-real --permitir-novavida-job-real
   - Iniciar em: <caminho do projeto>
5. Aba Condicoes: marcar "Iniciar a tarefa somente se o computador estiver
   com energia CA" e "Interromper se o computador passar a usar bateria" e
   "Ativar o computador para executar a tarefa".
6. Aba Configuracoes: NAO marcar "Executar a tarefa assim que possivel apos
   um inicio agendado perdido"; limite de tempo de execucao 3 dias (72h);
   regra para instancias simultaneas: "Nao iniciar uma nova instancia".
7. Salvar. Confirmar que o arquivo .env do projeto (item 6-c acima) esta
   preenchido antes do primeiro disparo automatico.

Alternativa via linha de comando (PowerShell, como administrador ou como o
proprio usuario que vai executar a tarefa), repetindo para cada um dos 10
horarios (exemplo do horario das 08:00; repetir trocando a hora):

  $action  = New-ScheduledTaskAction -Execute "<caminho>\.venv\Scripts\python.exe" `
               -Argument "-m src.orchestrator --once --permitir-consulta-real --permitir-novavida-job-real" `
               -WorkingDirectory "<caminho do projeto>"
  $trigger = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Monday,Tuesday,Wednesday,Thursday,Friday -At 08:00
  $settings = New-ScheduledTaskSettingsSet -DisallowStartIfOnBatteries -StopIfGoingOnBatteries -WakeToRun
  Register-ScheduledTask -TaskName "Automacao Astor Tech - Nova Vida" -Action $action -Trigger $trigger -Settings $settings -Description "Roda o ciclo completo (...)"

  Para os demais 9 horarios, usar Get-ScheduledTask + $task.Triggers +=
  New-ScheduledTaskTrigger ... e Set-ScheduledTask, ou simplesmente exportar
  o XML original (secao 8) e importar direto — mais simples e' o metodo do
  item 8 abaixo.

8. METODO MAIS SIMPLES E EXATO: IMPORTAR O XML ORIGINAL
==================================================================
O XML completo da tarefa (exportado com "schtasks /query /tn "Automacao
Astor Tech - Nova Vida" /xml ONE") esta salvo em:
  docs\Automacao_Astor_Tech_Nova_Vida_TaskScheduler.xml

Na maquina nova, apos copiar o projeto e ajustar os caminhos do .venv/python
dentro do XML (se o caminho do projeto mudar), basta importar:

  PowerShell (como o usuario que vai rodar a tarefa):
    Register-ScheduledTask -TaskName "Automacao Astor Tech - Nova Vida" -Xml (Get-Content "docs\Automacao_Astor_Tech_Nova_Vida_TaskScheduler.xml" | Out-String)

  Ou pelo Agendador de Tarefas (GUI): Acao > Importar Tarefa... e selecionar
  o arquivo XML.

  Isso recria os 10 gatilhos, a acao e todas as configuracoes de forma
  identica, sem precisar recriar manualmente cada horario.
